# Полная динамичная версия процесса рисования

## Итоговый файл

Главный файл — `full_process_art_edit_FINAL.mp4`. Это не короткий тизер: ролик длится **15 минут 12,9 секунды** и сохраняет всю последовательность художественной работы, от скетча и первых цветовых масс до финальной доводки света, материалов и атмосферы. Экспорт выполнен в **1920×1080, 60 fps**, с кодеками **H.264/AAC**.

> Главный принцип этой версии: ускорять повторяемые действия, но оставлять зрителю время увидеть, как формируются важные решения в рисунке.

| Задача | Реализация в файле |
|---|---|
| Сразу объяснить, ради чего смотреть | В первой секунде показан полный финальный арт без интерфейса. |
| Показать процесс по этапам | Скетч → контур и форма → базовый цвет → композиция → общий рендер → лицо → шляпа и края → материалы и шарф → одежда → мелкие штрихи → финальная доводка. |
| Сохранить кропотливую работу | Блоки лица, материалов, шляпы, одежды, мелких штрихов и последних акцентов занимают существенную часть ролика. |
| Убрать только бесполезное | Исключены заставка, краткая зеленая служебная вставка и контрастный технический просмотр, не меняющие сам рисунок. |
| Не обрезать арт | Во всех процессных сценах сохранен полный исходный кадр; агрессивное кадрирование не используется. |
| Поддержать темп | Повторяющиеся движения ускорены в 1,5–4 раза, а не сведены к нескольким секундам. |
| Добавить музыку | Сверху сведена длинная оригинальная инструментальная дорожка с постепенным развитием. |

## Монтажная структура

| Выходной блок | Исходный процесс | Скорость | Зачем он оставлен |
|---|---:|---:|---|
| Хук | Чистый финальный арт | 1× | Дает зрителю результат в первую секунду. |
| Скетч | Построение головы и лица | 2× | Показывает основу и пропорции. |
| Контур и форма | Уточнение силуэта и границ | 3× | Связывает набросок с живописной работой. |
| Базовый цвет | Крупные массы и первый свет | 3× | Видно, как рисунок становится читаемым. |
| Композиция | Расширение от портрета к широкому кадру | 2,5× | Важная смена композиционного решения. |
| Лицо и свет | Нос, глаза, плоскости и тени | 1,5× | Самый кропотливый и важный блок, оставлен медленнее. |
| Материалы и детали | Шляпа, шарф, одежда, края и мелкие штрихи | 2–2,5× | Сохраняет работу с фактурой, а не превращает ее в мельтешение. |
| Финальная доводка | Атмосфера, свет, баланс и последние акценты | 1,5–2,5× | Показывает, за счет чего работа получает законченный вид. |
| Финал | Полный арт | 1× | Закрывает ролик тем же результатом, который был заявлен в начале. |

## Повторяемый формат для следующих видео

Для регулярных выпусков используйте не фиксированную длину, а устойчивую логику монтажа: результат в первой секунде, обязательное деление по реальным этапам, замедление в местах художественного решения и ускорение только однообразной рутины. Если процесс занимает 30–60 минут, полноценная версия на 10–16 минут сохранит ощущение труда и даст аудитории материал для просмотра; короткую версию стоит делать отдельно как трейлер, а не вместо основного ролика.

| Формат выпуска | Рекомендуемая роль |
|---|---|
| Полная версия, 10–16 минут | Основной ролик процесса с сохранением содержательной работы. |
| Короткий ролик, 45–75 секунд | Отдельный анонс с результатом, несколькими переломными точками и ссылкой на полную версию. |
| Повторяемые элементы | Финальный арт в первой секунде, названия этапов, аккуратные ускорения, финальный показ. |
